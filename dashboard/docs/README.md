# HeroUI Dashboard Docs Pack

This pack contains professional documentation for implementing the Smart Farm dashboard redesign using HeroUI v3.0.3.

Files:

1. `heroui_v3_0_3_research_report.md`  
   Verified HeroUI v3.0.3 findings, official setup requirements, component facts, and project alignment audit.

2. `heroui_dashboard_implementation_guide.md`  
   Main visual blueprint and implementation constitution for AppShell, Sidebar, Overview, KPI cards, chart cards, tables, drawers, spacing, and validation.

3. `heroui_component_mapping_reference.md`  
   Exact component-to-dashboard mapping, wrapper contracts, and anti-patterns.

4. `heroui_existing_docs_alignment_patch.md`  
   Patch notes for updating existing HeroUI docs in the project after confirming v3.0.3.

5. `claude_code_heroui_docs_update_prompt.md`  
   A ready-to-use Claude Code prompt for creating/updating the docs inside the repo.

Use order:

1. Read research report.
2. Adopt implementation guide.
3. Apply alignment patch to existing docs.
4. Use component mapping before code migration.
5. Run Claude prompt locally.
