# Figure Captions and Thesis Placement Map

**Selected thesis title:** *A Smart Farm IoT Monitoring and Deterministic Agronomic Analytics Platform for Alfalfa Cultivation*

## Purpose

This file defines the official figure inventory, academic captions, suggested chapter placement, and recommended LaTeX labels for the Smart Farm IoT Master Thesis. It is intended to guide the Academic Thesis Builder when inserting diagrams, hardware photographs, dashboard screenshots, and validation evidence into the thesis.

## Caption and Usage Rules

- Use the captions below as the approved academic captions unless a later supervisor revision requires changes.
- Do not use raw filenames as figure captions.
- Introduce every figure in the text before inserting it.
- Explain the figure immediately after insertion.
- Keep implementation screenshots and validation screenshots separate.
- Do not claim that validation screenshots are generated by code if they are real dashboard screenshots.
- Use validation dashboard screenshots only in Chapter 5.
- Use dashboard feature screenshots from `DashBoredImages/` as final accepted dashboard interface figures.
- Keep Gemini-related figures framed as interpretation support, not deterministic computation.
- Keep Processed Data Viewer figures framed as transparency and lineage support, not as data mutation.

### Field Deployment Figures

| File | Figure role | Suggested caption | Suggested label | Suggested placement | Priority |
|---|---|---|---|---|---|
| `figures/field-main-node-deployment.png` | MAIN node at Pivot 1 field location | MAIN gateway node at the Pivot 1 field location during the pilot deployment. The IP65-rated enclosure provides dust and water-contact resistance. The node operates on battery power; electrical infrastructure visible in the surrounding area belongs to the field site and is not the node power source. | `fig:field-main-node-deployment` | Chapter 3, Field Deployment section | High |
| `figures/field-node2-soil-enclosure.png` | Node2 at Pivot 2 with CAT6 cable | Node2 soil sensing enclosure at the Pivot 2 field location. The CAT6 RJ45 outdoor cable carries the RS485 signal and power conductors to the in-ground soil sensor; it functions as a utility signal cable, not as an Ethernet connection. | `fig:field-node2-soil-enclosure` | Chapter 3, Field Deployment section | High |
| `figures/field-node3-weather-enclosure.png` | Node3 weather enclosure in field | Node3 weather sensing node at its field position during the pilot validation window. The IP65-rated enclosure houses the ESP32-C3, LoRa transceiver, and BME280 sensor, providing protection for outdoor atmospheric monitoring. | `fig:field-node3-weather-enclosure` | Chapter 3, Field Deployment section | High |

**IP65 rationale:** The IP65 rating was selected for its dust-total and water-jet protection. In the Saharan field context this addresses wind-borne sand, periodic humidity, and mechanical contact. IP65 does NOT imply submersion tolerance. The nodes are not described as "waterproof".

**CAT6 RJ45 rationale:** Selected for outdoor-rated insulation, humidity and soil-contact resistance, reliable copper conductors, and multi-conductor configuration accommodating RS485 signal and power lines. This cable carries RS485 serial communication only, not Ethernet. It connects node enclosure to in-ground soil sensor (Node2 only).

**Rainy-condition observation:** node_missing system events coincided temporally with rainy field conditions. This is a contextual observation only — not an experimentally isolated result. Causal attribution requires further controlled environmental validation. Never state "rain caused failure".
