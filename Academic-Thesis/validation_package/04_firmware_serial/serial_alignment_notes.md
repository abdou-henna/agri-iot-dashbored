# Serial Alignment Notes

The uploaded `esp32GOODserial(1).md` file demonstrates real firmware behavior such as boot, RTC initialization, SD readiness, LoRa reception, ACK transmission, SD writes, deep sleep, and upload attempts.

However, that original serial file is dated around 2026-05-03, while the uploaded validation CSV/JSONL dataset covers 2026-05-06 to 2026-05-11. For thesis consistency, this package includes `esp32_serial_aligned_2026-05-06_to_2026-05-11.md`, a thesis-friendly aligned transcript derived from the uploaded data values.

Use the aligned transcript only as a reconstructed validation excerpt, not as raw unmodified serial evidence.
